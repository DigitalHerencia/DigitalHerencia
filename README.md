### 👨‍💻 About Me
I’m a professional (and occasionally subversive) indie hacker who builds modern web applications with Next.js 15 and React 19. When I'm not busy reinventing the wheel—or deconstructing it for fun—I’m coding, iterating, and poking a bit of fun at the absurdity of tech trends. Currently, I’m channelling my energy into innovative solutions for New Mexico’s most forward-thinking industries. Because why settle for the ordinary when you can disrupt the status quo?

### 🛠️ My Tech Stack
- 💻 **Languages**: JavaScript (ESNext), HTML5, CSS3  
- 🌐 **Frontend**: Next.js 15, React 19, Redux (with a dash of sarcasm)  
- 🚀 **Backend**: Node.js, Express.js (API routes: because server-side rendering isn’t the only thing worth breaking)  
- 📊 **Data Visualization**: Nivo, D3.js (making numbers look almost interesting)  
- 🗄️ **Databases**: MongoDB (still the cool kid on the block)  
- 🔒 **Authentication**: JWT (keeping security simple, like my morning coffee)
